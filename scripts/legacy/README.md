# Legacy scripts

These are historical, one-off data-preparation and experiment scripts retained
for provenance only. They are **not maintained**, may reference paths or inputs
that no longer exist, and **do not reproduce the published results**.

The train/test splits, trained models, and figures in the manuscript are
generated by the analysis code in the manuscript repository
(<https://github.com/kbasecollaborations/trait-prediction-manuscript>) under its
`scripts/` directory (canonical entry points `create_data_splits.py` and
`ml_splits.py`), not by anything here.

The reusable library lives in `trait_prediction/`; the supported entry point for
library runs is `run_script.py` + `configs/` at the repository root.
